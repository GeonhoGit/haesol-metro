# 지하철 노선 복구

가상 도시 해솔시의 선로를 직접 설치해 출발역과 목적역을 잇는 Flutter 퍼즐 게임입니다. Android와 웹에서 같은 Dart 퍼즐 판정 코드를 사용합니다.

## 실행

Flutter 3.44 이상이 필요합니다.

```powershell
flutter pub get
flutter run -d chrome
```

Android 기기가 연결되어 있다면 `flutter run`에서 기기를 선택하세요. 배포용 웹 파일은 `flutter build web`, Android APK는 `flutter build apk`로 생성합니다.

## 조작

- 재고에서 선로 종류와 방향을 고른 뒤 `+` 표시된 칸을 탭하거나 클릭해 설치합니다. 설치한 조각은 교체하거나 `회수`할 수 있습니다.
- 공사 구역에는 선로를 설치할 수 없습니다. `운행 시작`을 누르면 빈 설치 칸, 선로 끝, 역 연결을 검사합니다. 붉은 테두리는 미설치 또는 끊어진 칸입니다.
- 최소 작업 횟수로 완성하면 3별을 받습니다. 잘못 설치해도 작업 횟수 제한 없이 수정할 수 있습니다.
- 힌트는 칸 하나의 필요한 선로 종류와 방향을 알려 줍니다. 3별 기록을 처음 달성하면 힌트 티켓을 받습니다.

## 콘텐츠와 저장

`assets/puzzles.json`에 구도심 스테이지 30개와 순환하는 7일치 일일 퍼즐을 수록했습니다. 날짜는 한국 표준시를 기준으로 결정됩니다. 별점, 최고 설치 기록, 코인, 힌트, 설정은 기기 또는 브라우저의 로컬 저장소에 기록됩니다.

핵심 판정은 `lib/game/puzzle.dart`, 콘텐츠 로딩은 `lib/game/catalog.dart`, 저장은 `lib/game/progress.dart`에 있습니다. 퍼즐 및 UI 검증은 `flutter test`, 정적 검사는 `dart analyze lib test`로 실행합니다.

보상형 광고, 온라인 순위, 꾸미기 구매와 계정 동기화는 연결되지 않았습니다. 광고 공급자와 배포 설정이 정해지기 전에도 모든 퍼즐을 플레이할 수 있습니다.
